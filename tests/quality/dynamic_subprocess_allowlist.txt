# [python-child] The child is a Python process (sys.executable, pip, uv, `-m navig`, or a
#   Python CLI such as pymobiledevice3). MEASURED on this machine: such a child writes the
#   ANSI code page to a redirected pipe -- utf-8 RAISES on its output and cp866 returns
#   garbage, while cp1251 is correct. `text=True` already means exactly that, so these are
#   CORRECT AS THEY ARE. They are listed only because the guard cannot tell them apart from
#   a genuinely unknown command. Converting them to the two-step decode would BREAK them.
#
# [mixed] The child may be either. Named separately because it is the one case where no
#   answer is right for both, and picking one silently breaks the other half.
