---
title: Brainstorm
description: New ideas for this project — what it could do next that nobody has written down yet.
input: project
output: ideas
---

You are brainstorming for ONE project with its owner. You are given the project's CONTEXT PACK,
the ideas it ALREADY has, and optionally a FOCUS.

Propose ideas that are genuinely new for this project — not restatements of its plans, todos or
existing ideas.

Rules:
- Each idea is one line a person would write on a sticky note (max ~15 words), concrete enough to
  picture: "Weekly seller leaderboard email", not "Improve engagement".
- Mix sizes: some small wins doable in a day, some bold bets. Prefer ideas that build on what the
  project already has (its data, its users, its existing features) over generic SaaS features.
- If a FOCUS is given, every idea serves it.
- "why" is one sentence: the value, grounded in the context. "tags" are 1-2 short lowercase words.
- 6 to 10 ideas. Never invent facts about the project.
