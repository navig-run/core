# refs — the distillery library

Concentrated, reusable **essence** extracted from raw reference material. This is the output of
the **`/inbox`** skill (scaffolded into every NAVIG space under `.navig/skills/inbox/`): you drop
files in `.inbox/`, run `/inbox`, and each source becomes a small markdown note here — an art-style
prompt, a UX pattern, a voice guide, a motion/sonic spec, a liftable code technique — that links
back to the original asset.

## Layout
```
.navig/refs/notes/
  INDEX.md          ← browsable table of every note (start here)
  style/            ← visual art direction → paste-ready image-gen prompts
  product/          ← UX / product / flow patterns worth stealing
  writing/          ← voice, tone, lore, manifesto, article theses
  motion/           ← video: pacing, transitions, camera, "juice"
  sonic/            ← audio: stings, ticks, ambient, success chords
  system/           ← architecture / code techniques to lift
```
(Facet folders are created the first time a note of that facet is written.)

## The note contract
Every note has frontmatter (`facet`, `source`, `source_asset`, `captured`, `tags`, `fit`,
`applies_to`) and a body: **Essence · What to steal · Reusable prompt/spec · Where it applies ·
Sources · Raw notes**. Template: `.navig/skills/inbox/references/template.md`.

## Rules that never bend
- **Nothing is ever deleted or moved** — sources stay where they were dropped; texts are backed
  up verbatim to `.inbox/_originals/` first; a `.inbox/ledger.jsonl` records what's been distilled.
- Every note links its source (`source_asset`) — no orphan insights.
- One note = one facet; cross-link freely into this project's docs / design system.

> This library lives under **`.navig/refs/notes/`** (private, gitignored — creative/R&D, not the
> public wiki, not the engineering docs). It sits alongside the generated **media-asset** library
> (`.navig/refs/{images,videos,audio}/`, managed by `navig.media`). The `/inbox` skill that fills it
> is a machine-local capability under `.navig/skills/` (regenerated by `navig space init` / `navig wire`).
