- **Bay install commands that could not run.** Personas, prompts, formations, web apps and plugins in the Bay catalog were listed with verbs no navig release has had — `navig persona use`, `navig prompt install`, `navig formation install`, `navig install webapp` — and the hidden, deprecated `navig plugin install`. Personas now install with `navig install add github:navig-run/community/personas/<id>` and plugins with `navig store install pip:<package>`; items whose community source is not yet in an installable format link to their source instead. A test now fails if any Bay install line names a command that does not exist.
